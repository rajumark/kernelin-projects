KERNELIN PROJECTS

Real GPU workloads, written in plain Kotlin.

Three applications built with Kernelin 0.1.0 from Maven Central. Each runs the same Kotlin functions on your GPU (WebGPU) and on the CPU, checks its own answers against exact formulas or ground truth, and shows measured speed. Open one in Chrome, Edge or Safari, on desktop or Android.

How to read these numbers

  • GPU times include copying data to the GPU and back. CPU times are the same Kotlin functions on the JVM (all cores) or compiled to Wasm (one browser thread).
  • Every project has unit tests that run the kernels as normal Kotlin, so the logic is tested before it ever reaches a GPU.
  • Building them found a real bug in Kernelin (helpers named like WGSL built-ins, such as uniform); it is fixed for the next release.
